## Resumo e Anotacoes
A hibridização do dataset brasileiro (BRSET) com o dataset internacional (ODIR5k) trouxe uma variabilidade morfológica crucial para a rede neural. O modelo híbrido (Cenário B) demonstrou desempenho substancialmente superior em dados nunca vistos antes no treinamento, reduzindo de forma drástica os Falsos Negativos na matriz de confusão e elevando o Recall (Sensibilidade) de 51.9% para 69.2%. Além disso, a métrica AUC-PR, essencial para analisar dados altamente desbalanceados, praticamente dobrou, saltando de 0.1763 para 0.3671. Isso comprova que a variabilidade de imagens preveniu que o modelo apenas memorizasse características específicas de uma única distribuição de sensores ou iluminação.
